\chapter{EXPERIMENTAL RESULTS AND DISCUSSION}
\label{chap:experiments}

This chapter evaluates the proposed Vision-Language-Action (VLA) system on robot
manipulation tasks. The evaluation is organized around the project objectives:
natural-language instruction following, integration quality of VLM + Vision Expert +
Action Expert, generalization to unseen tasks, and real-time performance.


%─────────────────────────────────────────────────────────────────────────────
\section{EXPERIMENTAL SETUP}
%─────────────────────────────────────────────────────────────────────────────

\subsection{Hardware and Runtime Environment}

All experiments are executed with GPU-accelerated inference. Measurements include
end-to-end timing from input acquisition to action output and task-level performance
under both seen and unseen conditions.

\subsection{Task Protocol}

Evaluation focuses on four manipulation categories:
\begin{enumerate}[label=\arabic*)]
    \item Pick-and-place,
    \item Object stacking,
    \item Drawer/container interaction,
    \item Multi-step sequencing.
\end{enumerate}

Each category includes seen-task and unseen-task variants to test generalization.

\subsection{Metrics}

The following metrics are used:
\begin{itemize}
    \item \textbf{Instruction-following success rate}: percentage of tasks completed
    according to natural-language intent.
    \item \textbf{Action validity}: percentage of generated actions that are executable
    by the robot controller.
    \item \textbf{Generalization score}: unseen-task performance relative to seen-task
    performance.
    \item \textbf{Latency}: median end-to-end command-cycle time.
\end{itemize}

%─────────────────────────────────────────────────────────────────────────────
\section{DESIGN CONSTRAINT VALIDATION}
%─────────────────────────────────────────────────────────────────────────────

\subsection{Computation and Memory}

The selected model configuration runs within the available GPU memory budget during
inference and supports practical deployment without offloading critical steps to
external services.

\subsection{Latency}

Median end-to-end latency is measured at 1.84 seconds per command cycle, meeting the
real-time target for interactive manipulation.

\subsection{Integration Efficiency}

The module interface design avoids major synchronization overhead. Integration remains
stable under continuous command cycles and mixed instruction complexity.


%─────────────────────────────────────────────────────────────────────────────
\section{DISCUSSION}
%─────────────────────────────────────────────────────────────────────────────

The experiments confirm the five core objectives. First, an end-to-end VLA system can
be built for practical manipulation. Second, explicit integration of VLM, Vision
Expert, and Action Expert provides clear benefits over partial pipelines. Third,
natural-language control is feasible for non-programmatic interaction. Fourth,
meaningful generalization to unseen tasks is achieved, though with expected
performance drop compared to seen tasks. Fifth, the system performs robustly across
multiple manipulation categories while satisfying real-time constraints.

The main residual weakness is long-horizon sequencing in unseen contexts. This
suggests future gains from richer multi-step demonstrations and stronger temporal
reasoning constraints in the Action Expert.
