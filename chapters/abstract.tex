\begin{center}
\textbf{\Large ABSTRACT IN ENGLISH}
\end{center}

This thesis presents Action Omni, an end-to-end Vision-Language-Action (VLA) framework for robot manipulation on the Dobot CR5 that enables execution of tasks directly from natural-language instructions, eliminating the need for task-specific programming. Unlike conventional robot control which requires manual code for each new task, VLA enables a single model to interpret free-form natural-language instructions, perceive the scene through RGB cameras, and generate continuous joint trajectories removing the need for hand-crafted state machines, predefined motion primitives, or task-specific re-programming when the task or environment changes. Developed under strict constraints including a 1-hour dataset, 8~GB VRAM training limit, and safety-restricted joint configurations, the system integrates a QwenVL3.5 2B perception backbone, a Diffusion Transformer (DiT) Action Expert, and a deterministic safety layer, trained on 530 simulation and 90 real-world episodes across Stay, Reach, and Grip tasks. Compared to SmolVLA, Action Omni achieves \textbf{55\%} success in simulation and \textbf{30\%} on the real-world Reach task, while requiring only 4~GB VRAM during inference.
