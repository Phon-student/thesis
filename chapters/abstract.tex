\begin{center}
\textbf{\Large ABSTRACT IN ENGLISH}
\end{center}

\vspace{0.5cm}

This thesis presents a Vision-Language-Action (VLA) framework for robot arm
manipulation in which visual perception, language understanding, and action generation
are integrated into a single control pipeline. The work addresses key limitations of
classical robot systems: task-specific design, weak generalization to unseen tasks,
limited natural-language interaction, and fragmented integration between vision,
language, and control modules.

The proposed architecture combines three coordinated components: a Vision-Language
Model (VLM) core for instruction grounding, a Vision Expert for task-relevant visual
feature extraction, and an Action Expert for executable robot action generation.
The system receives an RGB scene observation and a free-form natural-language command,
then produces structured manipulation actions suitable for robot-controller execution.

Experiments on representative robot manipulation tasks show that explicit VLM + Vision
Expert + Action Expert integration improves action validity and task success compared
with partial baselines. The system follows natural-language instructions reliably,
maintains practical real-time latency, and demonstrates improved performance on unseen
task settings relative to conventional task-specific pipelines. The results support the
feasibility of general-purpose VLA-based robot control under realistic computation,
data, and integration constraints.
